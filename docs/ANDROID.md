# Установка на Android

Коротко: **нельзя просто скопировать папку с `.py` на телефон и запустить её**.
На Android нет Python/Kivy «из коробки». Нужен **APK** — установочный файл, внутри
которого уже лежат Python, Kivy и наш код. Ниже — три способа его получить и как
потом установить.

## Что понадобится

- телефон на Android 7.0+ (в проекте `android.minapi = 24`);
- 15–20 ГБ свободного места на компьютере для первой сборки;
- 30–60 минут на первую сборку (скачиваются Android SDK/NDK);
- для способа А — аккаунт GitHub; для Б — Windows 10/11 с WSL2; для В — Docker Desktop.

Готовый APK будет весить примерно 30–60 МБ и работать без интернета.

## Способ А. GitHub Actions — без Linux и без установки Android SDK

Подходит, если не хочется ставить WSL и ждать сборку на своём компьютере.
Сборка идёт на серверах GitHub, APK скачивается готовым.

В проекте уже лежит файл `.github/workflows/build-apk.yml`. Он собирает debug-APK
при каждом пуше в `main`/`master` или по кнопке.

### 1. Загрузите проект на GitHub

Установите [Git для Windows](https://git-scm.com/download/win), создайте аккаунт
на GitHub и пустой репозиторий (без README, без .gitignore). Затем в PowerShell:

```powershell
cd путь\к\electricity-ege

git init
git add .
git commit -m "Электричество ЕГЭ: приложение на Kivy"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/electricity-ege.git
git push -u origin main
```

Если Git просит пароль — используйте не пароль аккаунта, а Personal Access Token
(или GitHub Desktop: **Add local repository → Publish repository**).

### 2. Запустите сборку

1. Откройте репозиторий на GitHub.
2. Вкладка **Actions**.
3. Слева **Build Android APK** → **Run workflow** → **Run workflow**.
4. Дождитесь зелёной галочки. Первая сборка — 30–60 минут, следующие быстрее.
5. Внизу страницы запуска скачайте артефакт **electricity-ege-apk-arm64** (ZIP).
6. Распакуйте ZIP — внутри один `.apk` для 64-битных телефонов
   (`...-arm64-v8a-debug.apk`). Он подходит для подавляющего большинства
   современных Android-устройств.

> Workflow собирает только `arm64-v8a`: это вдвое быстрее и не переполняет
> диск раннера. Если телефон старый 32-битный, соберите локально в WSL2 —
> в `buildozer.spec` указаны обе архитектуры.

> Артефакты GitHub хранятся 30 дней. Скачивать их может только владелец
> репозитория после входа в аккаунт.

### 3. Если сборка упала

Откройте упавший шаг **Build debug APK** и посмотрите последние 50–100 строк
лога. Типичные причины:

- GitHub ещё не включил Actions — включите во вкладке Actions.
- Лимит времени/места раннера — повторите запуск: кэш SDK часто переживает
  повторный запуск.
- В `buildozer.spec` для Android зафиксирован `kivy==2.3.1` — не меняйте его на
  2.3.2 без необходимости: под 2.3.2 в p4a может не быть совместимого рецепта.
- Ошибка p4a, связанная с Cython — выполните `python3 -m pip install "cython<3"`,
  затем `buildozer android clean` и повторите сборку.

## Способ Б. WSL2 на Windows — собрать локально

### 1. Установите WSL2 и Ubuntu

В PowerShell **от администратора**:

```powershell
wsl --install -d Ubuntu
```

Если Microsoft Store недоступен или установка зависла:

```powershell
wsl --install --web-download -d Ubuntu
```

Перезагрузитесь, задайте логин/пароль Linux. Проверка:

```powershell
wsl -l -v
```

Должно быть `Ubuntu` и `VERSION 2`. Если версия 1:

```powershell
wsl --set-version Ubuntu 2
```

### 2. Скопируйте проект в Linux

Собирать в `/mnt/c/...` очень медленно (и там бывают проблемы с правами).
Скопируйте проект в домашнюю папку Linux:

```powershell
wsl
```

```bash
cp -r "/mnt/c/Users/ПОЛЬЗОВАТЕЛЬ/Documents/deepseek-harness/default-workspace/electricity-ege" ~/electricity-ege
cd ~/electricity-ege
df -h .
```

Свободного места нужно около 15–20 ГБ: Android SDK, NDK и сборка занимают много.

### 3. Поставьте зависимости

```bash
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip python3-venv \
  autoconf libtool pkg-config zlib1g-dev libncurses5-dev \
  libncursesw5-dev libtinfo6 cmake libffi-dev libssl-dev

python3 -m venv ~/.venv-buildozer
source ~/.venv-buildozer/bin/activate
pip install --upgrade pip buildozer cython
java -version   # должна быть 17.x
```

Использовать отдельное окружение удобнее, чем `pip install --user`: на Ubuntu
24.04 системный pip заблокирован (PEP 668). Если `java -version` показывает не 17,
проверьте, что `openjdk-17-jdk` установлен именно внутри Ubuntu, а не только в
Windows.

### 4. Соберите APK

```bash
buildozer -v android debug
```

Первый раз buildozer скачает Android SDK/NDK (несколько ГБ) и соберёт
зависимости — это долго (30–90 минут). Готовые файлы появятся в `bin/`:

```bash
ls -lh bin/
```

### 5. Заберите APK в Windows

```bash
cp bin/*.apk /mnt/c/Users/ПОЛЬЗОВАТЕЛЬ/Downloads/
```

Или откройте проводник Windows из Linux:

```bash
explorer.exe .
```

## Способ В. Docker Desktop

Если установлен Docker Desktop с бэкендом WSL2, можно не ставить buildozer
в систему:

```powershell
cd путь\к\electricity-ege
docker run --rm -v "${PWD}:/home/user/hostcwd" kivy/buildozer -v android debug
```

APK появится в `bin\`. Первый запуск скачает образ и SDK, это тоже долго.
Если Docker ругается на путь с пробелами — перенесите проект в папку без пробелов.

## Установка APK на телефон

### Вариант 1. Через USB-кабель

1. Подключите телефон, выберите режим **Передача файлов (MTP)**.
2. Скопируйте `.apk` в папку `Download` на телефоне.
3. На телефоне откройте **Файлы → Загрузки**, нажмите на APK.

### Вариант 2. Через облако/мессенджер

Загрузите APK в Google Drive, Dropbox или отправьте себе в Telegram, скачайте
на телефоне и откройте файл.

### Вариант 3. Через adb (для разработчика)

Включите на телефоне **Для разработчиков → Отладка по USB**, подключите кабель
и выполните:

```powershell
adb install -r bin\electricityege-1.0.0-arm64-v8a-debug.apk
```

`adb` входит в Android SDK; если его нет, проще варианты 1–2.

### Разрешите установку

На современных Android установка APK «не из магазина» требует разрешения:

- **Android 8–14:** Настройки → Приложения → Специальный доступ →
  **Установка неизвестных приложений** → выберите приложение, через которое
  открываете APK (Файлы, Chrome, Telegram), и разрешите.
- На Xiaomi/Redmi дополнительно может понадобиться выключить «Оптимизацию MIUI»
  или разрешить установку в настройках безопасности.
- Play Protect может предупредить: **Подробнее → Всё равно установить**.
  Это нормально для APK, собранного вами.

### Если пишет «Приложение не установлено»

| Причина | Что делать |
| --- | --- |
| APK для другой архитектуры | Установите `arm64-v8a` для современного телефона |
| Уже установлена версия с другой подписью | Удалите старую версию приложения и установите заново. Прогресс при этом удалится |
| Мало места | Освободите 100–150 МБ |
| Android старше 7.0 | Нужен телефон с Android 7+ |
| Повреждённая загрузка | Скачайте APK заново, проверьте размер файла |

## Первый запуск

- Название на телефоне: **Электричество ЕГЭ**.
- Первый запуск может занять 3–10 секунд — Python-рантайм инициализируется.
- Интернет не нужен. Прогресс хранится в приватной папке приложения.
- Если экран чёрный дольше 15 секунд, подключите телефон по USB и посмотрите лог:

```powershell
adb logcat | findstr /i "python kivy"
```

```bash
# Linux/macOS
adb logcat | grep -iE "python|kivy"
```

Пришлите последние 50 строк — по ним видно, на чём упало.

## Обновление приложения

1. Измените `version` в `buildozer.spec` (например, `1.0.1`).
2. Пересоберите APK и установите поверх старой версии.
3. **Важно:** debug-APK, собранный на другом компьютере/в другом запуске GitHub
   Actions, может быть подписан другим debug-ключом. Android не даст установить
   его поверх старого. Тогда придётся удалить приложение (прогресс сбросится)
   или настроить release-подпись одним постоянным ключом.

Для себя обычно достаточно одного debug-APK. Для публикации в RuStore/Google Play
нужна release-подпись; это отдельная настройка buildozer (`buildozer android release`
и ваш keystore), в этот проект она не включена намеренно.

## Частые вопросы

**Можно ли установить просто папку с Python-кодом?**
Нет. Android не запускает `.py` напрямую. Нужен APK, который содержит Python,
Kivy и код.

**Можно ли использовать Kivy Launcher?**
Он устарел и не гарантирует работу на современных Android. Соберите APK — это
надёжнее.

**Приложение будет просить интернет/разрешения?**
Ему не нужны ни интернет, ни доступ к файлам/камере. Разрешения в
`buildozer.spec` не запрашиваются.

**Как сбросить прогресс?**
В приложении: главная → **Сброс**. Или Настройки Android → Приложения →
Электричество ЕГЭ → Память → **Очистить данные**.

**Где лежит APK, если собирал в WSL?**
`~/electricity-ege/bin/*.apk`. Скопируйте в `/mnt/c/Users/.../Downloads/`.

**Сборка падает на `libtinfo5` или Java.**
Поставьте Java 17 и пакеты из инструкции выше. На Ubuntu 24.04 иногда нужен
`libtinfo6`; в workflow используется Ubuntu 22.04 — там проверенная связка.

**`buildozer: command not found`.**
Активируйте окружение: `source ~/.venv-buildozer/bin/activate`. Если ставили
через `pip --user`, добавьте `export PATH="$HOME/.local/bin:$PATH"`.

**Нет прав администратора, чтобы поставить WSL/Docker.**
Локальная сборка в этом случае недоступна. Используйте способ А (GitHub Actions):
аккаунт GitHub не требует прав администратора на компьютере.

**Сборка идёт очень медленно или падает по памяти.**
Не собирайте в `/mnt/c/...`: скопируйте проект в `~/electricity-ege`. Закройте
тяжёлые приложения, оставьте 4+ ГБ RAM и 20 ГБ диска. Первая сборка может идти
30–90 минут — это нормально.
